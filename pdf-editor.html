PDF Text Editor

Select existing text on a page, edit it, and export a revised PDF. Files stay in your browser.

Choose a PDF to begin.
Your PDF pages will appear here.

Edit selected text

Tap a text item on the page to select it.

Font fidelity: The editor will try to extract and reuse an embedded font when the PDF exposes compatible font data. If it cannot, it will clearly fall back to a standard font. Export preserves the PDF page as vector/text content where possible, but replaced text is covered with a white patch; complex backgrounds, rotated text, unusual encodings and subset fonts may still need manual review. Keep your original PDF.
